# 🐠 3D 水草神仙魚缸

可互動的 3D 淡水水草缸 PWA，用 three.js 製作，可加到手機主畫面、離線使用。

**線上版：** https://kftseng2oo1.github.io/fish-tank/

## 功能

- **魚群**：神仙魚、七彩神仙、鬥魚、紅蓮燈、紅鼻剪刀、斑馬魚、孔雀魚、鼠魚、小精靈、黑殼蝦、桃花水母、麝香龜，可自由增減，並提示混養問題、負載量與建議水溫
- **擬真游動**：身體 S 形擺動、胸鰭拍動、各品種分開的魚群演算法、神仙魚與鬥魚停駐與追逐、鼠魚與蝦在底砂覓食、小精靈貼玻璃吃藻、水母一縮一放漂浮、烏龜在底部爬行並浮上水面換氣
- **水流場**：過濾器出水口的噴流、底部回流、氣泡柱，一起推動魚、水草、懸浮微粒和飼料
- **水中光影**：RGB 分別吸收的水色（越遠越偏綠）、投射在所有水中物體上的流動光紋、光束、反光
- **互動**：點魚跟拍、敲玻璃嚇魚、點水面餵食（浮性飼料／沉底錠）會起漣漪、日夜切換、打氣開關
- **我的魚缸**：儲存多組魚缸組合、用連結分享（`?tank=a3t12c4`）
- **拍照**：含浮水印，可直接分享或下載
- **螢幕保護模式**：隱藏介面、自動運鏡並輪流跟拍魚、防止螢幕休眠；網址加 `?kiosk=1` 開啟就直接進入
- **環境音效**：水聲、過濾器流水聲、氣泡聲，全部由程式即時產生
- **畫質**：高畫質（景深、光暈、陰影）與省電畫質，裝置吃力時自動降級；每種魚只用一次 instanced 繪製
- **養缸須知**：水質參數、必備設備、開缸流程、日常維護

## 網址參數

| 參數 | 說明 |
|---|---|
| `?tank=a3d5t12g4c4s8` | 載入指定魚群：a 神仙魚、d 七彩神仙、b 鬥魚、t 紅蓮燈、r 紅鼻剪刀、z 斑馬魚、g 孔雀魚、c 鼠魚、o 小精靈、s 黑殼蝦、j 桃花水母、k 麝香龜 |
| `?kiosk=1` | 直接進入螢幕保護模式（適合電視、平板當擺設） |

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 主程式 |
| `manifest.json` | PWA 設定 |
| `sw.js` | 離線快取（更新檔案時把 `CACHE` 版本號 +1） |
| `three.min.js` | three.js r128 |
| `three-post.js` | three.js r128 後製特效（景深、光暈） |
| `icon.svg`、`icon-*.png`、`apple-touch-icon.png`、`favicon-32.png` | 圖示 |
